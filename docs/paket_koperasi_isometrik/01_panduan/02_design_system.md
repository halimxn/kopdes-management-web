- Font: Inter (cadangan Segoe UI). Judul 600–700, isi 400–500.
- Kartu: putih, radius 16 (panel 24), bayangan `0 8px 24px rgba(59,91,219,.16)`.
- Tombol & menu: bentuk pil, aktif = biru solid + teks putih.
- Isometrik: sudut 30°, tile dasar 28px, cahaya dari kiri-atas (sisi kiri paling terang, sisi kanan ±12% lebih gelap).
- Status: Aktif biru, Selesai mint, Perhatian peach, Terlambat pink tua (#E5578A) + ikon, bukan warna saja.
- Tema gelap: kanvas #151B33, kartu #1F2747, objek tetap pastel tapi 15% lebih redup.
