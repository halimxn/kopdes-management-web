5. Pelacak pengiriman (kiri bawah)

Lima langkah Dipesan → Dikirim → Tiba → Diperiksa → Selesai. Selesai = lingkaran biru centang, sekarang = biru dengan cincin, nanti = abu. Kartu samping: ilustrasi truk, arah, judul, dok, pill tahap.

6. Label peta

Pill putih (ikon + nama) dengan ekor; terpilih biru + chip status; peringatan kuning; lahan kosong = lingkaran "+" 44 px tanpa teks; ponsel < 600 px = ikon saja kecuali terpilih.

7. Wajib dan dilarang

Wajib

  • Angka dari data; memuat/galat "—"; pencatatan belum aktif dijelaskan.
  • Ilustrasi WorldIcon untuk objek, ikon garis hanya untuk aksi.
  • Status bertulisan; warna hanya penguat.
  • Area sentuh ≥ 44 px; teks ≥ 11 px.
  • Kartu putih radius 14, bayangan lembut, tanpa blur latar.

Dilarang

  • Delta "+15", ETA, kecepatan, persentase tepat waktu karangan.
  • Merek/logo pemasok di truk atau kartu.
  • Tombol dekoratif tanpa tindakan, slogan.
  • Mengganti palet kartu dengan token halaman operasional.
  • Gambar tempel/screenshot sebagai latar dunia.
